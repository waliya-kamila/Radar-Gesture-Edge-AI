# Firmware: on-device gesture recognition in C

The complete pipeline as microcontroller firmware: streaming pre-processing of every radar frame, the INT8 CNN after every 90-frame window, and **only the recognised gesture** sent over the serial port.

- Pure C99, no dynamic memory, no libc or libm (only `memcpy`/`memset`, provided in `mcu/libc_min.c`).
- INT8 kernels reproduce the TensorFlow Lite graph and fuse each convolution with the next operation (conv1+pool, conv2+pool, conv3+global-average-pool), so the 46 KB output of the first convolution is never stored.
- Target: Arm Cortex-M4F with 512 KB flash / 128 KB SRAM (linker script enforces the budget). Simulated on the Arm MPS2-AN386 board in QEMU; text output and the radar stream go through ARM semihosting (standing in for a UART and the sensor interface).

```
src/radar_pipeline.c   pre-processing + fused INT8 CNN (portable)
src/model_data.h       INT8 weights, generated by tools/export_model.py
mcu/                   Cortex-M4 start-up, semihosting, main loop, linker script
tests/                 host tests against Python/TFLite, host semihosting shim, Unicorn runner
build_mcu.sh           arm-none-eabi-gcc build
```

## Verification

| Check | Result |
|---|---|
| Pre-processing vs. Python (`scipy.signal.hilbert`) | max error 8 × 10⁻⁷ of peak |
| INT8 CNN vs. TensorFlow Lite (60 windows, participant 8) | 60/60 identical predictions, scores within ±1 |
| Inference RAM (activations, fused kernels) | 26,048 B (ST Edge AI compiler: 25.6 KiB) |
| Pre-processing state (filter + window buffer) | 36,832 B |
| Same firmware ELF on emulated Cortex-M4 vs. native PC build | identical output |

## Build and run

```sh
# Cortex-M4 firmware
sudo apt-get install gcc-arm-none-eabi qemu-system-arm
sh build_mcu.sh
qemu-system-arm -M mps2-an386 -nographic \
    -semihosting-config enable=on,target=native -kernel firmware.elf   # reads ./stream.bin

# host test (any PC)
python tests/make_host_vectors.py <demo_dir> <out_dir>
cc -std=c99 -O2 -Isrc src/radar_pipeline.c tests/host_test.c -lm -o host_test && ./host_test <out_dir>
```

`stream.bin` is a sequence of raw radar frames, each `189 range bins × 3 radars` float32 values (bin-major); notebook 09 creates it from recordings of a participant that the model never saw.
